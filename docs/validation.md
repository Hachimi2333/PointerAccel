# 验证记录

环境：Fedora 44、x86-64、KWin/Plasma 6.7.5、Qt 6.11.2、libinput 1.31.3；SELinux Enforcing、Secure Boot 启用。

独立 GUI 版本（2026-10-29）的 CTest 结果：**29/29 通过**。测试运行于隔离 HOME、模拟系统目录和独立 D-Bus/KWin 会话，不替换当前桌面的系统模块。

## 已执行的验证

- Qt Quick 模拟模块测试：整份配置提交、写入锁、过期版本冲突、离线保存、运行应用失败、D-Bus 超时和无效响应、配置损坏时禁止保存。
- 跨页面草稿、外部修改同步与冲突、后台刷新期间编辑、设备断开与不支持设备、trace 开关、导出保存配置及已有 trace、算法状态重置。
- 实际 QML 控件鼠标与键盘操作，关闭对话框的取消、放弃、应用后关闭及离线保存后保留窗口；明暗调色板、600×500 小窗口和 125%/200% 缩放截图，检查底部按钮不被裁切。离屏平台的暗色场景显式注入根控件调色板。
- 嵌套 KWin 中通过真实 GUI 控制器统一应用，CLI 查询到相同设置；GUI 退出后模块仍然处理输入，原始位移验证继续通过。
- 当前 Plasma Wayland 会话中只读打开设置、设备和诊断三个页面，未出现 QML 运行错误；配置文件逐字节保持不变。截图位于构建目录 `gui-qa/wayland-live/`。此检查未操作真实会话的设置或重置算法状态。
- 验证 CLI 不链接 Qt GUI/Quick 库，GUI 不链接 KWin 私有库。

- 原引擎全部速度档位、EPP 开关、参考模型、显示 DPI、极限坐标、零报告与状态测试。
- 在真实 ELF 完整 RELRO 测试库中安装和还原三个函数入口；验证拦截期间及还原后的映射权限与安装前一致。
- X/Y 读取顺序、原返回值、非所属线程、事件地址复用、溢出标记及 100 万份合成报告采集。
- 普通启动的嵌套 KWin 中经正式插件管理接口加载模块；保留 `SCHED_RR`、优先级 1。
- 测试版模块在嵌套桌面按登录配置自动加载，注入合并报告，检查逐报告加速、多鼠标共享状态、热插拔、触摸板透传、125% 缩放、设备排除、5000 份报告下的 4096 份记录上限、禁用恢复、批次不匹配回退与模块卸载。
- Wayland 相对指针及 XWayland XI2 RawMotion 客户端逐报告顺序和数值校验；重放时逐报告发送 frame，避免 XWayland 仅保留最后一份位移；整数加速输出为零时仍保留非零 raw 报告。
- 临时 HOME 和模拟系统目录中执行真实安装脚本：首次与重复安装、首次失败回滚、升级失败回滚、配置保留、离线卸载、KWin 配置按字节恢复、保留安装后新增的其他设置、修改文件冲突时拒绝卸载。
- ELF Build ID 文件解析与当前进程的映射标识一致；错误运行库 Build ID 的模块工厂拒绝创建输入处理对象，嵌套 KWin 继续运行。
- 独立检查服务实际加载正式模块；同版本哈希变化、模块/清单损坏、用户清单损坏、未完成事务、同一安装会话、未支持的版本均不加载模块。
- 在线升级的模拟磁盘不匹配保留已加载模块的 `active` 与 `running_compatible`；速度设置继续生效，`doctor` 同时报告下次启动需要修复。
- 删除安装来源目录后，通过保留的源码快照执行真实修复安装流程；当前模块保持驻留，修复后显示需要重新登录。另在独立临时 HOME 中完成从快照全新配置、编译、26 项测试、模拟系统部署和离线卸载。
- 通过命令替身模拟配置失败、测试失败及构建期间 RPM 构建标识变化；确认用户文件与系统模块、兼容记录均保持原字节。
- 旧直接自启布局迁移，保留首次安装备份与用户设置；系统提交前失败回滚服务和两端清单；首次安装和重复安装被 SIGKILL 后通过 `--recover` 恢复原始文件。
- 用户服务通过 `systemd-analyze --user verify` 检查，包括带空格、美元符号和百分号的 XDG 路径；服务管理器保留旧 `XDG_SESSION_ID` 时优先依据 KWin 的 D-Bus 实例判断新登录。

采集层 100 万份合成报告的一次测量约为 20.8 ns/份；这只衡量测试替身中的采集与取出，不包括 KWin、Wayland、绘制或真实硬件延迟。

可复现命令为 README 中的 CMake/CTest 命令。测试失败时 CTest 会显示具体场景，安装脚本不会继续安装。

## 尚需在本机真实会话验证

- 管理员权限安装真实系统模块，重新登录后的自动加载。
- 实际鼠标与触摸板、按钮、侧键、滚轮、拖拽和游戏输入。
- 真实多屏混合缩放跨屏行为、休眠恢复，以及高回报率下的整条输入链路延迟。

这些项目需要用户完成安装并重新登录。当前测试结果不宣称已经独立验证 Windows 二进制实现，也不宣称测量了真实硬件的端到端延迟。
